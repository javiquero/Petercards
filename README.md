# Cáscaras y Paraguas

Juego de cartas por turnos para móvil: plátanos, cáscaras y paraguas contra Don Bigote (la máquina).

- Todo el juego está en `index.html` (HTML + CSS + JS, sin dependencias ni build).
- El arte está en `assets/` (recortes en WebP de las ilustraciones originales).
- Se despliega como sitio estático en Vercel: cada push a `main` publica en producción.

## Probar en local

```bash
npx serve .
```
